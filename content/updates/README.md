# Content drop-zone

One folder per page (matching the slugs in `content/PAGE-INVENTORY.md`). Luke drops research
documents, build plans, scripts or notes into a page's folder at any time, in any format.

Before building or revising any page, check its folder here first. These documents outrank
both the salvaged WordPress copy in `content/salvage/` and any local repo README — they are
the top-ranking source for that page's content.
