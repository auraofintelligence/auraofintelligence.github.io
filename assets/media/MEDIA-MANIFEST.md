# Media manifest

Every image slot on the site: filename, page, purpose, salvage source, status.
Status is internal bookkeeping only: never rendered on the site.

**How to replace an image**: drop a new file into `assets/media/` using the exact
same filename as the row below. No code changes needed: the page picks it up.
Naming convention: `<page-slug>--<purpose>-<nn>.webp` (purposes: hero, portrait,
gallery, card, poster, bg).

All 2024-era images were harvested from the live WordPress site 2026-07-12,
deduplicated from WordPress's resolution variants, and converted to webp
(quality 82, max width 1920 for heroes / 1200 for others).

**Width and height columns are the image's real pixel dimensions** (measured with
`ffprobe`, added 2026-07-12). Always use these exact values in each page's `<img
width height>` attributes, never a guessed or rounded number: a mismatched
width/height ratio stretches the image once `height: auto` in `styles.css` kicks
in, which is what caused the July 2026 "squishy images" bug. If a replacement
image lands with different real dimensions than this table, re-measure it
(`ffprobe -v error -select_streams v:0 -show_entries stream=width,height -of
csv=s=x:p=0 <file>`) and update both this row and the page's `<img>` tag.
